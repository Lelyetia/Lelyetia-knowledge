    深度学习¶

    当前版本 v0.1.0最后更新 2026-11-03查看版本记录 ↓

    本分类结合书籍与视频课程，覆盖神经网络原理、PyTorch 数据处理和模型训练实践。

    资源 类型 关注内容
    深度学习入门：基于 Python 的理论与实现（鱼书） 书籍 NumPy 实现、反向传播、初始化与对照实验
    动手学深度学习 书籍 理论、代码、经典网络与任务实践
    动手学深度学习 v2 视频课程 概念讲解、代码演示与工程问答
    PyTorch 深度学习快速入门教程 视频课程 Dataset、DataLoader 与完整训练流程

    鱼书侧重基础组件的实现，《动手学深度学习》覆盖更广的模型与任务，视频课程可用于补充讲解与操作过程。可按当前问题交叉使用。
