## 内容概要

《机器学习》以机器学习的概念、方法与理论为主线，南瓜书则围绕西瓜书中的公式补充推导与解释。两者结合，能够把算法的使用条件、数学表达与推导过程联系起来。

基础部分涉及训练集与测试集、特征与标签、过拟合与欠拟合，以及基于混淆矩阵的准确率、精确率、召回率和 F1 分数等评估指标。这些概念也是阅读后续模型与实验结果的基础。

## 资源评述

这组资料的价值在于解释模型与评估方法背后的逻辑。阅读公式时，需要结合符号含义、假设条件和具体任务理解，适合与小规模代码实验配合使用。具有线性代数、概率统计与微积分基础，有助于连贯阅读相关推导。

## 学习参考

- 先建立基本术语与评估流程，再逐步深入算法推导，避免只记住公式形式。
- 用混淆矩阵中的具体计数核对各项指标，理解不同指标关注的错误类型。
- 可以按“运行示例—解释结果—调整方法—补充原理”的顺序组织学习，将工程问题与数学概念对应起来。
- 处理视觉任务时，将本书的评估思想与[计算机视觉实践](../computer-vision/index.md)结合，关注指标与任务目标是否一致。
