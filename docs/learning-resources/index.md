## 如何使用

- **建立概念与理论联系**：结合《机器学习》与南瓜书理解术语、评估方法和公式推导。
- **从原理过渡到实现**：从鱼书的 NumPy 实现入手，再结合《动手学深度学习》与视频课程完成训练流程。
- **围绕视觉任务实践**：通过 OpenCV 熟悉图像处理，并在实验仓库中关注配置、数据划分与结果记录。

同一资源可能涉及多个领域，这里按主要学习目标归类；书籍、课程和仓库的类型信息保留在资源页中。
