# 计算机科学基础

## 简介

欢迎来到**计算机科学基础**！

在本单元中，我将那些经过我个人学习或了解的有关计算机科学基础的学习资源进行整理，部分情况下可能会包括我的课程笔记。在“其他学习资源（未完成）”中将给出其他一些我我收藏夹下的学习资源。

在开始计算机及其相关专业（如计算机视觉、人工智能,etc.）的学习前，我认为掌握计算机科学的基础知识是在该领域长期研究与发展的前提。尽管并非所有使用计算机的学生们都将计算机科学的基础知识视为学习其他领域或者使用计算机开始进行科研的前提，就像我一样，在经历超过一年的深度学习、计算机视觉等领域的学习与研究后，并没有增长太多有关计算机的学科知识。尽管在AI时代，很多问题都可以询问AI甚至让AI通过操纵电脑来解决。但是扪心自问，如果一个计算机专业的学生在经过数年的学习后在使用诸如Git等工具时依然需要询问AI，那随着使用次数越多，与AI对话的次数将会越多。我们可以将这个操作视为n的复杂度。那么为什么我们不在一开始，或者说使用AI完成类似任务的一段时间后，开始着手学习这方面的知识呢？尽管学习过程中我们或许需要较高的时间来掌握，但一旦掌握后我们便可以在每次遇到类似任务时使用自己的知识而不是借助AI。这样我们完成任务的复杂度仅仅取决于我们专注于操作所用时的本身。此外，通过系统性的学习，我们能够看到这些操作进行组合时散发的各种诱人的可能性--which AI只能输出给你唯一的也就是他当下输出的那种可能性。在面对问题时，我们将“主动的”看到更多的选择，而不是等着AI来替代我们完成。
