# Welcome to Lelyetia's Knowledge Base!

欢迎来到**lelyetia的个人知识库**！本项目主要记录我在学习中产生的资源，包括知识、资源、笔记等内容。主要记录内容包括：**计算机基础**、**计算机视觉**、**人工智能（传统机器学习与深度学习）**、**计算机图形学**等内容，一切内容将取决于我的学习历程。愿我们保持进步，to~屏幕前的你。

## 关于我

中国普通大学本科生，目前**大三**在读，喜欢研究**计算机科学、人工智能、计算机图形学**等领域的知识。更多有关我的介绍在[我的个人主页](https://lelyetia.github.io/)中。

## 一些注意事项

1. 本知识库由我个人负责，由于升学等原因，不能保证在本科期间进行深度的完善。不过只要我还**活着**，应该还是会持续更新的>_<。
2. AI时代，“产出”变得廉价，因此我希望本知识库的大多数内容（尤其是知识点部分）由我个人完成。尽管它可能不适合每个人理解事物的方式，并且不够完整、存在错误，不过我会不断进行更新的。如果你发现了错误，或者有补充与建议，欢迎通过[issue](https://github.com/lelyetia/lelyetia-knowledge/issues)提出。
3. 正如第二点所说的，由于绝大部分内容为纯手敲，所以markdown的语法将会使用较少，尤其是加粗这些，仅在必要时使用。
4. 如果你觉得本知识库对你有帮助，欢迎关注[我的Github](https://github.com/lelyetia)并[star本项目](https://github.com/lelyetia/lelyetia-knowledge)。如果需要，个人微信及打赏方式如下，欢迎与我交流学习。
5. 关于打赏：计算机社区的**开源精神**十分伟大，这意味着很多情况下不需要任何的付费即可获得很多优秀的学习资源。如果你觉得一些东西对你有帮助但作者并没有收取费用（就像PCL的作者龙腾猫跃），那么可以通过打赏的方式支持作者噢~！
